# MCP协议

MCP（Model Context Protocol）约定应用如何发现和调用外部工具、资源和提示模板。它管的是连接方式，不管模型如何做决策。决策仍在 [[Agent循环]] 里。

## 三个角色

- **Host**：用户正在用的应用，例如编辑器或你自己的 agent。
- **Client**：host 里负责连某一台 server 的一端。
- **Server**：真正提供工具的进程，可以是本地命令，也可以是远程服务。

Host 把 server 暴露的工具收进模型的工具列表。模型仍然只看到名字、说明和参数；执行请求经 client 转到 server。

## 它解决什么

同一个文件、浏览器或数据库工具，可以接到不同的 agent 应用上，而不必为每个框架重写一遍绑定。规格和示例见项目笔记 [[mcp]]。

## 它不解决什么

权限、提示词、多代理分工、评估。这些仍然要在应用里决定。Server 能做的事，默认都要当成有副作用的能力来授权。
