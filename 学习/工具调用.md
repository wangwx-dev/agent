# 工具调用

工具是模型可以请求、由运行时执行的函数。模型不直接碰操作系统。它只产出结构化的调用请求：工具名和参数。运行时校验参数、执行、把结果变成下一条消息。

## 一个工具要写清的内容

- 名字和给模型看的说明。说明差，模型就会选错工具。
- 参数模式。能用 schema 约束的，不要靠 prompt 口头约定。
- 返回值如何变成文本。过大的结果要截断，并告诉模型被截断了。
- 副作用：只读，还是会改文件、发请求、花钱。

## 常见坑

- 把业务策略写进工具描述，循环本身却没有停止和权限判断。
- 工具返回整页 HTML 或整文件，把上下文撑满。
- 一个工具做太多事。模型更擅长在几个窄工具之间选择。
