# 评估与可观测

Agent 的输出不稳定。没有轨迹，就只能凭感觉改提示词。可观测是把一次运行的输入、工具调用、工具结果、模型回复和耗时记下来。评估是拿一组固定任务看这些运行有没有变好。

## 至少留下的字段

- 运行 ID、时间、模型名
- 每一跳的消息和工具参数
- 工具是否失败、失败文本
- 最终回答
- token 或延迟（有就记，没有就先空着）

[[langfuse]] 是现成的 trace 后端。阶段 1 的小应用也可以先把 JSON 写到本地，关键是字段稳定，而不是先上平台。

## 小任务集

为自己的应用留 5 到 10 个真实任务，包含：成功路径、工具失败、权限不够、不该调用工具的问题。每次改提示词或换模型都重跑，保留结论在应用笔记里。

评估指标先用任务是否完成，再谈分数。自动打分本身也是一个会错的模型调用。
