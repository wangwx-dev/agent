# 学习地图

目标是能独立做出一个可观测、可中断、带工具的 agent 应用，并说清它和主流开源实现的差别。按阶段推进。后一阶段用到前一阶段的笔记，不要平行开一堆框架教程。

## 阶段 1 — 单代理循环

先掌握一次「模型决定 → 执行工具 → 把结果送回模型 → 直到停止」。

- [[Agent循环]]
- [[工具调用]]
- 对照阅读：[[smolagents]]、[[openai-agents]]
- 练习：在 `apps/` 做一个只含一个工具循环的小应用，不引入大型框架

过关标准：能画出一次带工具调用的时序，能指出循环在哪停止，能让失败的工具结果回到模型而不是直接崩掉。

## 阶段 2 — 状态、记忆、规划

循环能跑之后，问题会变成「跑到一半怎么停、怎么续、记住什么」。

- [[规划]]
- [[记忆]]
- 对照阅读：[[langgraph]]、[[pydantic-ai]]

过关标准：说得清短期消息、检查点、长期记忆三者的差别，以及什么时候不该上向量库。

## 阶段 3 — 工具协议

工具不要绑死在某一个框架的函数签名上。

- [[MCP协议]]
- 对照阅读：[[mcp]]

过关标准：能解释 MCP 里 host、client、server 谁调用谁，以及它解决的是发现和调用工具，不是 agent 策略。

## 阶段 4 — 多代理与软件形态

多代理不是默认架构。先看清楚单代理加路由已经能做什么。

- [[多智能体]]
- 对照阅读：[[crewai]]、[[microsoft-agent-framework]]、[[mastra]]、[[google-adk]]
- 想做成产品时再看：[[dify]]
- 看垂直场景：[[openhands]]、[[browser-use]]

过关标准：能给一个具体任务选择「单代理」「工作流」「多代理」中的一种，并说明代价。

## 阶段 5 — 评估与上线

没有轨迹就无法改 prompt 或换模型。

- [[评估与可观测]]
- 对照阅读：[[langfuse]]

过关标准：一次真实运行能留下可检索的 trace，并且有一个自己写的小任务集用来回归。
