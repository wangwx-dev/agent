# browser-use

用浏览器完成任务的 agent。页面状态是观察，点击、输入、导航是动作。适合看「观察太大时如何摘要」。

## 为什么读

浏览器 DOM 比普通工具返回值更容易撑满上下文。看它如何选择元素、如何描述当前页面，比看通用框架的工具注册更有用。
