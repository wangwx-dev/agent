# Agent 实验室

在这个目录里做三件事：学 agent 应用开发、拆优秀开源项目、写自己的应用。知识用 Obsidian 管，代码和克隆的仓库分开存放。

## 目录

| 路径 | 用途 |
| --- | --- |
| `首页.md` | Obsidian 入口 |
| `学习/` | 概念和课程笔记 |
| `研究/项目/` | 每个开源项目一篇笔记 |
| `应用/` | 自己的应用设计笔记 |
| `模板/` | 新建笔记时插入 |
| `收件箱/` | 还没归类的记录 |
| `日志/` | 每日笔记 |
| `apps/` | 自己写的应用代码，一个应用一个子目录 |
| `refs/` | 只在本地克隆的开源仓库，不提交 |

## 用 Obsidian 打开

1. 安装 [Obsidian](https://obsidian.md/)。
2. 选择「打开本地仓库」，指向本目录 `D:\personal\agent`。
3. 若提示是否信任仓库，选择信任（需要读取本目录里的 `.obsidian` 配置）。
4. 打开 `首页`。

已写好的配置：新建笔记默认进 `收件箱/`，模板目录是 `模板/`，每日笔记进 `日志/`，图谱和搜索会忽略 `apps/` 与 `refs/`。

## 日常怎么用

1. 灵感先丢进收件箱。
2. 学一个概念：命令面板运行「模板: 插入模板」，选「学习笔记」，链到 `学习地图`。
3. 开始读一个仓库：用「项目研究」模板。代码克隆到 `refs/<名字>`，不要把仓库内容抄进笔记，只记判断和出处。
4. 要做自己的应用：用「应用立项」模板写清楚边界，再在 `apps/<名字>/` 里写代码。

笔记用中文。代码、目录名、标识符用英文。
